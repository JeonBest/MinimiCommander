# Minimi Commander 기술 스펙 v0.1

## 1. 문서 개요
- 버전: `v0.1.0`
- 기준 코드: 현재 `master` 브랜치 최신 커밋
- 목적: 구현 완료된 MVP의 기술 스펙을 코드 기준으로 정리

## 2. 기술 스택
- 런타임/렌더링: `Phaser 3.90.0` (Arcade Physics)
- 언어: `TypeScript`
- 빌드/개발 서버: `Vite 6`
- 패키지 매니저: `npm`

## 3. 실행/빌드
- 개발 서버: `npm run dev`
- 프로덕션 빌드: `npm run build`
- 빌드 결과 미리보기: `npm run preview`

## 4. 프로젝트 구조
```text
src/
  main.ts                # Phaser GameConfig 및 Scene 등록
  style.css              # 기본 스타일
  game/
    EntryScene.ts        # 엔트리 씬(시작/설명)
    BattleScene.ts       # 전투 씬(핵심 루프)
    config.ts            # 밸런스/월드 상수
    types.ts             # 도메인 타입
    upgrades.ts          # 업그레이드 정의
```

## 5. 씬 구성

### 5.1 EntryScene
- UI 요소:
  - `게임 시작` 버튼: `BattleScene`으로 전환
  - `게임 설명` 버튼: 오버레이 패널 표시
  - `닫기` 버튼: 설명 오버레이 숨김
- 설명 오버레이는 게임 규칙(자동 소환, 조작, 골드, 승패, 기지 반격)을 안내

### 5.2 BattleScene
- 생성 순서:
  1. 런타임 상태 초기화
  2. 월드/카메라 설정
  3. 임시 텍스처 생성(유닛/기지/포탑/장애물)
  4. 기지/포탑/장애물/유닛 그룹 구성
  5. HP 바, HUD, 업그레이드 UI 생성
  6. 입력(조이스틱 + WASD) 바인딩
  7. 초기 유닛 스폰
- 프레임 업데이트 루프:
  - 입력 반영 -> 소환 -> AI 갱신 -> 포탑 공격 -> 유닛 업데이트 -> 사망 정리 -> UI/승패 판정

## 6. 도메인 모델

### 6.1 팀/승패/AI 모드
- `Team`: `ally | enemy`
- `MatchStatus`: `RUNNING | WIN | LOSE`
- `AIMode`: `RALLY | ASSAULT`

### 6.2 핵심 상태 객체
- `UnitState`: HP/공격력/사거리/쿨다운/이동속도/사망 여부
- `BaseState`: 팀, 현재 HP/최대 HP, 좌표, 스프라이트
- `TurretState`(BattleScene 내부): HP/사거리/쿨다운/사망 여부
- `MatchState`:
  - `gold`
  - `spawnIntervalByTeam` (`ally`, `enemy`)
  - `upgradeLevels` (`spawnRate`, `enemySpawnRate`)
  - `status`
- `AIStrategyState`:
  - 모드(`RALLY`/`ASSAULT`)
  - 집결지/공격 목표
  - 모드 전환 기준 유닛 수

## 7. 월드/오브젝트 스펙

### 7.1 월드
- 전장 크기: `900 x 900`
- 카메라: 화면 비율 기반 FIT 줌 + 중앙 정렬

### 7.2 기지
- 위치:
  - 아군: `(100, 100)`
  - 적군: `(800, 800)`
- 형태: 단일 원형 텍스처 + 원형 물리 바디
- 수치:
  - HP: `3000`
  - 렌더 크기: `156`
  - 충돌 반경: `64`
- 규칙:
  - 유닛이 기지 사거리 근접 시 기지 공격 수행
  - 기지를 공격하는 유닛은 기지 반격 피해(`12`)를 즉시 받음

### 7.3 포탑
- 배치: 각 기지 전방 오프셋(`112`) 위치
- 수치:
  - HP `1800`
  - 데미지 `42`
  - 사거리 `280`
  - 공격 쿨다운 `650ms`
- 특징:
  - 원거리 빔 이펙트
  - 파괴 가능
  - 아군이 적 포탑 파괴 시 추가 골드 획득(`30`)

### 7.4 유닛
- 기본 수치:
  - HP `100`
  - 데미지 `20`
  - 공격 쿨다운 `1000ms`
  - 공격 사거리 `45`
  - 추적(어그로) 사거리 `180`
  - 이동속도 `110`
  - 충돌 반경 `16`
- 팀별 최대 수: `40`

### 7.5 장애물
- 정적 장애물 2개(직사각형)
- 모든 유닛과 충돌

## 8. 전투 루프 상세

### 8.1 스폰
- 시작 시 양팀 각각 2기 선스폰
- 기본 자동 스폰 주기: `3.0초`
- 스폰 위치:
  - 각 팀 포탑 주변(측면/후방 랜덤 오프셋 + 지터)
  - 월드 경계 내로 클램프

### 8.2 플레이어 지시
- 모바일/마우스: 가상 조이스틱
  - 데드존 적용 (`0.24`)
  - 감도 이징(`pow(1.9)`)
  - 조이스틱 드래그 시작 좌표 기준으로 벡터 계산
- PC: `WASD`
  - 목표지점을 현재 목표 기준으로 연속 이동 (`260 px/s`)
- 지시 목표:
  - 아군 유닛 중심점(anchor) + 입력 방향 * 거리
  - 거리 범위: `40 ~ 200`
- 조이스틱/키보드 입력 중(`isPlayerCommandActive = true`)에는
  - 아군 유닛이 근거리 적 자동 추격을 중단하고 지시 목표 우선

### 8.3 적 AI
- 모드 전환:
  - `RALLY -> ASSAULT`: 적 유닛 수 `>= 8`
  - `ASSAULT -> RALLY`: 적 유닛 수 `<= 4`
- 모드별 전략 목표:
  - `RALLY`: 아군 기지 방향의 집결지로 이동
  - `ASSAULT`: 아군 기지로 진군

### 8.4 타게팅/공격 우선순위
- 유닛은 가장 가까운 적 대상 탐색:
  1. 적 유닛
  2. 적 포탑
- 사거리 내면 정지 후 공격
- 사거리 밖이면:
  - 조건 충족 시(적팀 유닛 또는 아군 자동추격 허용 상태) 추격 이동
  - 아니면 전략 목표(아군: 지시점, 적군: AI 목표)로 이동
- 기지 근접 시 기지 공격 로직 우선 처리

### 8.5 보상/경제
- 적 유닛 처치: `+10 골드`
- 적 포탑 파괴(아군이 파괴한 경우): `+30 골드`

### 8.6 업그레이드
- v0.1 제공 업그레이드: `소환 가속`
- 비용: `100 + 50 * 현재레벨`
- 효과:
  - 아군 자동 스폰 주기 `-250ms`
  - 최소 주기 `1000ms`

### 8.7 승패/재시작
- 승리: 적 기지 HP `<= 0`
- 패배: 아군 기지 HP `<= 0`
- 결과 오버레이에서 `Restart` 클릭 시 `scene.restart()`로 즉시 재시작

## 9. 충돌 정책
- 유닛-유닛: 아군/적군 내부 충돌 + 상호 충돌 활성화
- 유닛-기지: 모든 조합 충돌 활성화
- 유닛-포탑: 모든 팀 조합 충돌 활성화
- 유닛-장애물: 충돌 활성화
- 결과적으로 유닛 겹침을 최소화하고, 기지/포탑 관통을 방지

## 10. HUD/UI 표시 정보
- 실시간 HUD:
  - 골드
  - 아군/적군 소환 레벨 및 현재 소환 주기(초)
  - 아군/적군 포탑 HP
  - 적 처치 수
  - 적 AI 모드
- 기지 상단 HP 바:
  - 아군/적군 각각 개별 표시
  - `현재 HP / 최대 HP`

## 12. 확장 포인트
- `upgrades.ts`에 업그레이드 정의 추가로 확장 가능

- `types.ts`의 `UpgradeLevels` 확장 후 HUD/버튼을 다중 업그레이드 UI로 확장 가능
- AI 전술 확장

- 리소스 교체
  - 현재는 코드 기반 임시 그래픽 텍스처
  - 추후 스프라이트/타일맵 리소스로 대체 가능
